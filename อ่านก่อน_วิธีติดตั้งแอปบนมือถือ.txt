แอปบ้านพัก รพ.วานรนิวาส บนมือถือ (หน้าห่อเว็บแอป)
=====================================================

ไฟล์ในชุดนี้
  index.html              หน้าเปิดแอป (ใส่ลิงก์เว็บแอปไว้แล้ว)
  manifest.webmanifest    ชื่อแอป ไอคอน สีของแอป
  sw.js                   ให้เปิดแอปได้เร็ว (ไม่เก็บข้อมูลของระบบไว้ในเครื่อง)
  icons/                  ไอคอนแอป

ห้ามเปลี่ยนชื่อไฟล์ และต้องวางไฟล์ทั้งหมดไว้ที่เดียวกัน (โฟลเดอร์ icons ด้วย)


ขั้นที่ 1  วางไฟล์บน GitHub Pages (ฟรี ทำครั้งเดียว)
-----------------------------------------------------
1. สมัคร/เข้าสู่ระบบ https://github.com
2. มุมขวาบน กด + → New repository
   - Repository name: hhms   (ตั้งชื่ออื่นได้ ใช้ตัวอังกฤษพิมพ์เล็ก)
   - เลือก Public → กด Create repository
3. ในหน้าที่ขึ้นมา กดลิงก์ "uploading an existing file"
4. ลากไฟล์ทั้งหมดในชุดนี้ (รวมโฟลเดอร์ icons) ไปวาง → กด Commit changes
5. ไปที่ Settings (แถบบน) → Pages (เมนูซ้าย)
   - Source: Deploy from a branch
   - Branch: main  และ  / (root) → กด Save
6. รอ 1–2 นาที รีเฟรชหน้า จะขึ้นลิงก์ เช่น
   https://ชื่อบัญชี.github.io/hhms/
   ลิงก์นี้คือ "ลิงก์แอป" ที่จะให้ทุกคนใช้


ขั้นที่ 2  เพิ่มลงหน้าจอโทรศัพท์
-------------------------------
iPhone / iPad (ต้องใช้ Safari)
  1. เปิดลิงก์แอปใน Safari
  2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) → "เพิ่มไปยังหน้าจอโฮม"
  3. กด "เพิ่ม" — จะได้ไอคอน "บ้านพัก" บนหน้าจอ

Android (Chrome)
  1. เปิดลิงก์แอปใน Chrome
  2. กดเมนู ⋮ มุมขวาบน → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"
  3. กด "ติดตั้ง"

คอมพิวเตอร์ (Chrome / Edge)
  เปิดลิงก์แอป → กดไอคอนติดตั้งที่ช่องที่อยู่ (รูปจอมีลูกศร) → ติดตั้ง


ใช้งานประจำ
-----------
- อัปเดตโค้ดระบบใน Apps Script ได้ตามปกติ ไม่ต้องแก้ไฟล์ชุดนี้
  (ลิงก์ /exec ของเว็บแอปไม่เปลี่ยนเมื่อออก "เวอร์ชันใหม่" ในจัดการการทำให้ใช้งานได้)
- ต้องแก้ไฟล์ชุดนี้เฉพาะเมื่อสร้างการทำให้ใช้งานได้ "รายการใหม่" ซึ่งได้ลิงก์ /exec ใหม่
  ให้เปิด index.html บน GitHub → กดรูปดินสอ → แก้บรรทัด var APP_URL = '...' → Commit
- เปิดไปหน้าที่ต้องการได้ตรง ๆ เช่น  https://ชื่อบัญชี.github.io/hhms/#/board  (แผงห้องพัก)

ข้อควรรู้
---------
- iPhone อาจให้ล็อกอินใหม่บ่อยกว่าเปิดในเบราว์เซอร์ (Safari จำกัดข้อมูลของเว็บที่เปิดซ้อนในหน้าอื่น)
- ถ้ายังเห็นแถบ "แอปพลิเคชันนี้สร้างโดยผู้ใช้ Google Apps Script" ให้ตรวจว่าเปิดจากลิงก์แอป (github.io)
  ไม่ใช่ลิงก์ script.google.com
